تطبيق «شركة مجد الوطنية»

ملفات هذا المجلد هي التطبيق. ترفعها مرة واحدة على الإنترنت، ثم يثبّت كل موظف التطبيق من رابطه.

الرفع على GitHub (مجانًا):
1. ادخل github.com بحسابك واضغط New repository. اكتب اسمًا مثل app، واختر Public، ثم Create repository.
2. اضغط uploading an existing file (أو Add file ثم Upload files)، واسحب كل الملفات الموجودة هنا (وليس المجلد نفسه)، ثم Commit changes.
3. من Settings ثم Pages: في Branch اختر main ثم Save. بعد دقيقة أو اثنتين يظهر رابط مثل https://اسمك.github.io/app/
4. افتح البرنامج، ومن الإعدادات ← تطبيق البرنامج الصق هذا الرابط واضغط «حفظ رابط التطبيق».

التثبيت:
- أندرويد: افتح الرابط في Chrome واضغط «تثبيت التطبيق» (أو من القائمة ⋮ ← إضافة إلى الشاشة الرئيسية).
- آيفون: افتح الرابط في Safari، ثم زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- الكمبيوتر: افتح الرابط في Chrome أو Edge واضغط أيقونة التثبيت في آخر شريط العنوان.

إذا تغيّر رابط البرنامج (نشر جديد بدل تعديل النشر نفسه)، نزّل الملفات من جديد من البرنامج وارفعها مكان القديمة.
